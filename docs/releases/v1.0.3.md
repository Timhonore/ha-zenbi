**Rettet: profilbilleder og klassetrin.**

- Billedstien fra Zenbi skal slutte med `/small`. Den bare URL giver 404;
  den fulde billedsti er nu kontrolleret og returnerer JPEG.
- Klassetrin, der er gemt som valg-id'er, slås op i Zenbis feltdefinitioner.
  Klasseoplysninger kan stadig være tomme, hvis Zenbi ikke leverer et felt eller navn.
- Emnevalg, HA-personbilleder og fallback til initialer er bevaret.

Opdater til **v1.0.3** i HACS, og genstart Home Assistant.
Ret dashboardets JavaScript Module-resource til:

```text
/zenbi-card/zenbi-card.js?v=1.0.3
```

Genindlæs dashboardet. Profiloplysninger indlæses ved integrationsopstart.

Validering: 26 syntetiske Python-tests, browserprøver, HACS og hassfest.
