Zenbi-integration og Skoleoverblik-card udgives samlet som **v.1.0**.
Home Assistants interne versionsnummer er `1.0.0`.

- Lektier, opgaver, ugeplaner, beskeder, opslag og kalendere samlet i HA.
- Børnevalg, dansk visning, officielle Zenbi-ikoner og korteditor.
- Kompakt vandret scrollrække til fanerne, også på mobil.
- Faneskift bevarer fokus og dashboardets scrollposition.
- Ugeplaner uden en titel vises som **Ugeplan**, også med gamle data.

Opdater i HACS, og genstart Home Assistant. Dashboard-resource (JavaScript Module):

```text
/zenbi-card/zenbi-card.js?v=1.0.0
```

Genindlæs dashboardet eller luk og åbn HA-appen.

Ved skift fra en installation med commit-id til den første release kan det være
nødvendigt at vælge **Download igen** i HACS og vælge `v1.0` én gang.

HACS tjekker custom repositories automatisk hver 48. time.
**Opdater oplysninger** kan hente nye udgivelser med det samme.

Validering: 23 syntetiske Python-tests, browserprøver, hassfest og HACS.
Integrationen er uofficiel og er ikke udgivet eller godkendt af Zenbi.
