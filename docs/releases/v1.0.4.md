**Mindre afstand mellem navn og klassetrin.**

Børneknapperne bruger nu en kompakt linjehøjde og 1 px mellem linjerne.
Det undgår den store afstand fra HA-temaets nedarvede linjehøjde.

Opdater i HACS, genstart HA og ret JavaScript Module-resourcen til:

```text
/zenbi-card/zenbi-card.js?v=1.0.4
```

Genindlæs dashboardet eller luk og åbn HA-appen.
