**Vælg selv emner på hvert Zenbi-card.**

Kortets visuelle editor har nu afkrydsninger for **Lektier, Kalender, Beskeder,
Ugeplan og Opslag**. Mindst ét emne skal være valgt.

- Kun valgte faner og tællere vises.
- Kortet starter på en valgt fane, hvis den tidligere fane er skjult.
- Kort med kun beskeder/opslag skjuler børnevælgeren.
- Børnesensorer får klasse og navn som attributter samt profilbillede fra Zenbi,
  hvis billedmetadata findes. Live billedvisning er endnu ikke bekræftet.
- Cardeditoren kan vælge eksisterende HA-personer til børnenes profilbilleder;
  billede og klasse fra Zenbi bruges som standard. HA-personerne ændres ikke.
- Hvert kort har sit eget valg; integrationens sensorer og kalendere fortsætter.
- Eksisterende kort viser stadig alle emner. `show_posts: false` understøttes fortsat.

Opdater Zenbi i HACS, genstart HA, og ret dashboardets JavaScript Module-resource til:

```text
/zenbi-card/zenbi-card.js?v=1.0.1
```

Genindlæs dashboardet. Åbn derefter kortets editor og vælg **Emner på kortet**.
YAML-eksempel med kun lektier og kalender:

```yaml
type: custom:zenbi-card
topics: [homework, calendar]
```
