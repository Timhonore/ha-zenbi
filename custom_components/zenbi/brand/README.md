# Zenbi brand assets

The icon is Zenbi's official app icon, obtained from its public PWA manifest:

https://app.zenbi.dk/assets/img/logos/512x512-maskable.png

`icon@2x.png` is the original 512×512 PNG. `icon.png` is a 256×256 reduction.
Brand assets and trademarks belong to Zenbi and are excluded from this
repository's MIT license. This integration is independent and unofficial.

Home Assistant 2026.3+ supports the bundled `brand/` directory. Older Home
Assistant versions may show a placeholder icon.
